HAPPY SUNDAY — IBADA NJEMA WEBSITE

1. Extract ZIP.
2. Fungua folder kwenye Visual Studio Code (File > Open Folder).
3. Fungua index.html.
4. Tumia Live Server, au fungua index.html kwenye browser.

Picha hutumia Unsplash na zinahitaji intaneti. Hakuna API key inayohitajika.
Website ina kurasa 10, ujumbe wa Happy Sunday, ibada njema, mwaliko wa karibu ibadani, uchaguzi wa muda/mazingira, animation za maua, countdown na mwisho wenye ujumbe “YESU anakupenda”.
